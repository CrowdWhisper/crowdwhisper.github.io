{% capture t %}**Bitcoin Core**, the software used to run Bitcoin nodes, disclosed a medium-severity bug on 20 November and released fixes in versions 30.5 and 31.3; version 32.1, out since 27 October, already had the fix [6]. A peer could repeat one transaction ID up to 50,000 times in a single message, and each such message stalled a node for over a dozen seconds, during which it processed no blocks or other messages [6][7]. The advisory describes a temporary stall, not a way to take coins, and says an automated AI scan found the flaw [6][7]. The older 29.x series is end of life and gets no fix [6].{% endcapture %}
